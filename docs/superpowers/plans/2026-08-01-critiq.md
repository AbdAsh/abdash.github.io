# Critiq Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Paste a URL, get an SEO and answer-engine review — deterministic checks plus LLM judgment, merged and deduplicated, as a shareable permalinked report. Deployed at `labs.abdash.net/critiq`.

**Architecture:** One Edge Function does everything: SSRF-guard the URL, fetch it, parse with `deno-dom`, build a structured digest, run deterministic checks over the digest, send the digest plus extracted text to OpenRouter for judgment findings, merge with checks winning on mechanics, persist, return a slug. No browser, no screenshots, no third-party service.

**Tech Stack:** Vite 8 · React 19 · TypeScript 6 · `deno-dom` · OpenRouter `MODEL_QUALITY` · `@labs/platform`.

## Global Constraints

- **Prerequisite: the platform plan is complete.**
- **The SSRF guard is a correctness requirement, not hardening.** It is the only thing between an attacker-supplied URL and our network, and it must run before any outbound request.
- No JavaScript rendering. A page whose content requires JS is **reported as a critical finding**, not treated as a tool failure.
- Deterministic checks are authoritative for mechanics; the LLM is credited only with judgment. Every finding carries `source: 'check' | 'llm'`.
- `MODEL_QUALITY`, text only. No vision model.
- **No storage allocation.** Findings JSON lives in Postgres; 30 MB budget.
- Vite `base: '/critiq/'`.

- [ ] **Step 3: Implement validation**

```ts
export class SsrfError extends Error {
  status = 400
  constructor(msg: string) { super(`Refusing to fetch this URL: ${msg}`) }
}

const V4_BLOCKED: [number, number][] = [
  [0x00000000, 8], [0x0A000000, 8], [0x7F000000, 8], [0xA9FE0000, 16],
  [0xAC100000, 12], [0xC0A80000, 16], [0x64400000, 10], [0xE0000000, 4],
]

function v4ToInt(ip: string): number | null {
  const parts = ip.split('.')
  if (parts.length !== 4) return null
  let n = 0
  for (const p of parts) {
    const v = Number(p)
    if (!Number.isInteger(v) || v < 0 || v > 255) return null
    n = (n << 8) | v
  }
  return n >>> 0
}

export function isBlockedAddress(ip: string): boolean {
  const v4 = v4ToInt(ip)
  if (v4 !== null) {
    return V4_BLOCKED.some(([base, bits]) => {
      const mask = bits === 0 ? 0 : (0xFFFFFFFF << (32 - bits)) >>> 0
      return (v4 & mask) === (base & mask)
    })
  }
  const v6 = ip.toLowerCase().replace(/^\[|\]$/g, '')
  return v6 === '::1' || v6 === '::' ||
         v6.startsWith('fc') || v6.startsWith('fd') ||   // unique local
         v6.startsWith('fe80') ||                        // link-local
         v6.startsWith('::ffff:')                        // v4-mapped
}

export function assertPublicUrl(raw: string): URL {
  let url: URL
  try { url = new URL(raw) } catch { throw new SsrfError('not a valid URL') }

  if (url.protocol !== 'http:' && url.protocol !== 'https:') {
    throw new SsrfError('only http and https are allowed')
  }
  const port = url.port === '' ? (url.protocol === 'https:' ? '443' : '80') : url.port
  if (port !== '80' && port !== '443') throw new SsrfError('only ports 80 and 443 are allowed')

  const host = url.hostname.toLowerCase().replace(/\.$/, '')
  if (host === 'localhost' || host.endsWith('.localhost') || host.endsWith('.internal')) {
    throw new SsrfError('internal hostname')
  }
  if (isBlockedAddress(host)) throw new SsrfError('private or reserved address')

  return url
}
```

- [ ] **Step 4: Implement `guardedFetch` with per-hop revalidation**

Enforce a 15 s `AbortSignal.timeout`, reject non-HTML `Content-Type`, and stop reading at `maxBytes` (default 2 MB).

The one worth writing carefully:

```ts
Deno.test('js-only-content fires on an empty SPA shell', () => {
  const findings = runChecks(
    { wordCount: 12, scriptCount: 9, textHtmlRatio: 0.01 } as Digest, null, null,
  )
  const f = findings.find((x) => x.id === 'js-only-content')
  assertEquals(f?.severity, 'critical')
})

Deno.test('js-only-content does not fire on a normal script-using page', () => {
  const findings = runChecks(
    { wordCount: 1400, scriptCount: 8, textHtmlRatio: 0.28 } as Digest, null, null,
  )
  assertEquals(findings.find((x) => x.id === 'js-only-content'), undefined)
})
```

A modern content site loads plenty of scripts; the finding must key on *text absence*, not script presence, or it will fire on almost everything.

```sql
create schema if not exists critiq;
grant usage on schema critiq to anon, authenticated, service_role;

create table critiq.reports (
  id         uuid primary key default gen_random_uuid(),
  slug       text unique not null,
  owner_id   uuid not null references auth.users(id) on delete cascade default auth.uid(),
  url        text not null,
  status     text not null default 'complete',
  grades     jsonb,
  findings   jsonb,
  digest     jsonb,
  created_at timestamptz not null default now()
);

create index reports_owner_idx on critiq.reports (owner_id, created_at desc);
create index reports_cache_idx on critiq.reports (url, (created_at::date));

alter table critiq.reports enable row level security;

create policy reports_own on critiq.reports for all to authenticated
  using (owner_id = auth.uid()) with check (owner_id = auth.uid());

-- Permalinks: anyone may read a completed report by slug, but nobody can list
-- another user's history, because there is no path to enumerate slugs.
create policy reports_public_by_slug on critiq.reports for select to anon, authenticated
  using (status = 'complete');

grant select, insert, update, delete on critiq.reports to authenticated;
grant select on critiq.reports to anon;
```

- [ ] **Step 2: Write the RLS tests**

- [ ] **Step 3: Assemble `index.ts`**

Order matters and is not negotiable: `preflight` → `getCaller` → **cache lookup by (url, today)** → `consumeQuota` only on a cache miss → `assertPublicUrl` → `guardedFetch` → fetch `robots.txt` and `sitemap.xml` (guarded, best-effort, failures non-fatal) → `buildDigest` → `runChecks` → `judge` → `mergeFindings` → `gradeDimensions` → insert → return `{ slug, grades, findings }`.

Checking the cache before consuming quota means resubmitting the same page is genuinely free, as the spec promises.
